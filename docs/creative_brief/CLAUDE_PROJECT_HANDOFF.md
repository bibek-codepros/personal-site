# HOME — Project Handoff

Hello Claude,

Welcome to HOME.

Before making any changes, I'd like you to understand what this project is.

HOME is **not** a portfolio.

HOME is **not** a resume.

HOME is **not** a startup landing page.

HOME is a living collection of stories, memories, reflections and experiences.

The project has been carefully planned over many weeks.

Every page, every story and every design decision has been intentionally created to support one goal:

Help visitors understand the human behind the work.

Please do not treat HOME like a normal Next.js project.

Treat it like a digital home.

# Existing Philosophy

When implementing anything,

remember these priorities.

Story

↓

Reading Experience

↓

Emotion

↓

Performance

↓

Visual Polish

Never reverse that order.

---

# Content Rules

Always use the real written content.

Do not generate placeholder paragraphs.

Only placeholder images are acceptable until final assets are available.

Everything else should feel production-ready.

---

# Design Rules

Minimal.

Calm.

Warm.

Editorial.

Readable.

Timeless.

Do not make HOME look like:

A SaaS dashboard

A startup landing page

A portfolio template

A blog

Instead,

make it feel like reading a beautifully designed book.

---

# Animation Rules

Animations should slow readers down.

Not speed them up.

Every animation should have purpose.

If removing an animation improves the reading experience,

remove it.

---

# When Unsure

If any implementation decision conflicts with the philosophy documents,

always follow the philosophy.

Never optimize for trends.

Always optimize for meaning.

---

# Working Method

For every implementation sprint:

1. Read the relevant content.

2. Understand the story.

3. Implement.

4. Review against Project Philosophy.

5. Refine.

Do not rush.

HOME values craftsmanship over speed.

---

Thank you for helping build HOME.

Your job is not simply to write code.

Your job is to protect the feeling this project creates.
