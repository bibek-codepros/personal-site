# PART 02
# DESIGN

> "People rarely remember layouts.
> They remember how a place made them feel."

---

# Design Is Not Decoration

The purpose of design in HOME is not to impress.

It is not to demonstrate creativity.

It is not to follow trends.

Design exists for one reason.

To make the stories easier to feel.

Every decision should support the narrative.

Never compete with it.

---

# The Feeling We Are Designing

Imagine this.

It's Saturday morning.

Rain is falling outside.

Someone opens HOME.

There is no rush.

No notification.

No advertisement.

No pop-up asking for an email.

Only quiet.

Only space.

Only stories.

That is HOME.

---

# Emotional Keywords

Every page should feel:

Warm.

Calm.

Honest.

Personal.

Quiet.

Reflective.

Hopeful.

Timeless.

If a design introduces anxiety, pressure or noise...

it does not belong.

---

# HOME Should Feel Like...

HOME should feel like:

• reading a favourite book in a quiet café

• opening an old leather notebook

• looking through family photographs

• watching rain through an airplane window

• drinking coffee with someone you've known for years

Not:

• browsing a startup website

• using a SaaS dashboard

• scrolling social media

• reading documentation

---

# White Space

White space is not empty.

White space gives stories room to breathe.

Never fill empty space because it "looks unfinished."

Silence is part of the experience.

Readers need moments to pause.

Let them.

---

# Typography

Typography is HOME's most important design element.

Visitors will spend far more time reading than clicking.

Typography should disappear.

Readers should never think:

"Nice font."

They should simply continue reading.

Guidelines:

• Comfortable line length

• Large line height

• Strong hierarchy

• Minimal font combinations

• Excellent readability on desktop and mobile

If typography becomes noticeable,

it is probably trying too hard.

---

# Photography

Every photograph should answer one question.

Why does this memory matter?

Never add photos because a section feels empty.

Never use stock images.

Never use overly polished lifestyle photography.

Real moments are always more powerful than perfect ones.

Photographs should feel documentary.

Natural.

Honest.

Slightly imperfect.

Just like memories.

---

# Illustration

Illustrations should whisper.

Not shout.

They exist to support emotion.

Possible illustration themes:

• old Nokia phone

• airplane window

• coffee mug

• notebook

• mountain skyline

• handwritten notes

• travel tickets

• small maps

The style should remain consistent throughout HOME.

Simple.

Editorial.

Minimal.

Timeless.

---

# Color

HOME should never rely on color for excitement.

Instead,

color should create comfort.

Imagine old paper.

Coffee.

Wood.

Morning light.

Muted greens.

Warm grays.

Deep charcoal.

Soft earth tones.

Avoid highly saturated colors.

Avoid gradients that demand attention.

The story should always remain the strongest visual element.

---

# Motion

Animation is breathing.

Not fireworks.

Every movement should have purpose.

Animations should help readers slow down.

Never speed them up.

Good examples:

Gentle fade.

Subtle reveal.

Soft slide.

Reading progress.

Quiet transitions.

Avoid:

Parallax everywhere.

Oversized hover effects.

Bouncy animations.

Aggressive motion.

Motion should disappear into the experience.

---

# Icons

Icons exist to communicate.

Not decorate.

Every icon should belong to one family.

Minimal.

Consistent.

Quiet.

Avoid mixing icon styles.

Avoid emojis inside the interface unless they are intentionally part of the story.

---

# Components

Every reusable component should feel related.

Buttons.

Cards.

Quotes.

Notebook entries.

Navigation.

Gallery.

Everything belongs to one visual language.

Visitors should never feel like they've entered another product.

---

# Images vs Stories

Whenever there is uncertainty...

Choose the story.

Not the image.

Words are HOME's strongest medium.

Visuals support them.

They never replace them.

---

# Minimalism

Minimalism is not about removing everything.

It is about removing everything unnecessary.

If an element does not improve understanding...

remove it.

If an interaction exists only because it looks cool...

remove it.

If a section becomes stronger after deleting something...

keep it deleted.

---

# Accessibility

Beautiful experiences should be available to everyone.

Accessibility is not an optional improvement.

It is part of good design.

Readable fonts.

Keyboard navigation.

Color contrast.

Semantic structure.

Every visitor deserves the same experience.

---

# The Final Question

Before approving any design,

ask:

"Does this help someone feel closer to the story?"

If the answer is yes,

keep it.

If not,

simplify it.
