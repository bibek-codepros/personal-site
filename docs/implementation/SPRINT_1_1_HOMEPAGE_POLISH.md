# SPRINT 1.1 — Homepage Polish

Status: In Progress

Priority: Highest

---

# Goal

The Homepage is functionally complete.

Do NOT build new pages.

Do NOT add new features.

Do NOT work on Becoming, Contact, Notebook or AI.

Your only responsibility is to elevate the Homepage from "implemented" to "premium."

Think like a Senior Product Designer and Senior Frontend Engineer working together.

---

# Overall Direction

The Homepage should feel less like a website.

It should feel like arriving somewhere.

The visitor should slow down.

Read.

Reflect.

Continue.

Never rush them.

---

# Task 01 — Hero

Current hero works.

Now make it memorable.

Improve:

- Better typography hierarchy
- More whitespace
- Better vertical rhythm
- Better CTA spacing
- More premium layout
- Editorial feeling

Do NOT change the copy.

Improve presentation only.

---

# Task 02 — Typography

Typography is now the highest priority.

Improve:

- Heading sizes
- Paragraph spacing
- Reading width
- Font weights
- Line height
- Visual rhythm

Every paragraph should feel comfortable.

No dense blocks.

---

# Task 03 — Layout

Increase whitespace significantly.

The homepage currently feels slightly compressed.

Increase spacing between:

Sections

Headings

Paragraphs

Buttons

Timeline

Footer

Whitespace is part of the design.

---

# Task 04 — Motion

Revisit every animation.

Requirements

Remove anything unnecessary.

Use only:

Fade

Opacity

Small translateY

Small stagger

Animation should be felt.

Never noticed.

# Task 06 — Responsive

Review every breakpoint.

Desktop

Tablet

# Task 07 — Accessibility

Verify

# Task 08 — Performance

Review

Images

Animations

---

# Task 09 — Components

Review every component.

Remove duplication.

Simplify props.

Increase reusability.

Improve naming where necessary.

---

# Task 10 — Polish

Review the homepage slowly.

Pretend you have never seen it before.

Ask

Does this feel premium?

Does this feel calm?

Does this feel welcoming?

Does this feel human?

If not,

continue refining.

---

# Important

Do NOT invent new sections.

Do NOT rewrite the narrative.

Do NOT redesign the homepage.

Only elevate the existing implementation.

- Accessibility improvements
