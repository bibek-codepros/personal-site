# NOTEBOOK EDITORIAL RULES

Status: Production Ready

Version: 1.0

---

# Purpose

Notebook is a long-term writing project.

This document ensures every future note feels like it belongs to the same book.

Whether a note is written today or ten years from now,

it should still sound like HOME.

Consistency creates identity.

---

# The Golden Rule

Write to remember.

Never write to impress.

If a note exists only because it sounds clever,

delete it.

If it exists because it genuinely mattered,

keep it.

---

# The Voice

Notebook should always sound like a conversation.

Imagine sitting in a quiet coffee shop.

Someone asks,

"So... what have you been thinking about lately?"

That's the tone.

---

# Simple Language

Prefer:

simple

clear

honest

natural

Avoid:

complex vocabulary

overly poetic language

corporate words

buzzwords

motivational clichés

Readers should never need to reread a sentence to understand it.

---

# Write From Experience

Every note must begin with experience.

Experience →

Observation →

Reflection

Never reverse the order.

Don't begin with wisdom.

Earn it.

---

# Show, Then Reflect

Good

I still remember copying my teammate's HTML because I didn't know where to start.

That day taught me that beginning imperfectly is still beginning.

Bad

Always start before you're ready.

Readers trust stories.

Not advice.

---

# Avoid Teaching

Notebook is not a classroom.

Do not explain.

Do not lecture.

Do not instruct.

Simply share.

Let readers discover their own meaning.

---

# Keep The Ego Small

HOME is never about proving yourself.

Avoid writing like:

"I achieved..."

"I built..."

"I became..."

Instead write:

"I realised..."

"I learned..."

"I noticed..."

"I understood..."

Growth feels more human than achievement.

---

# Honesty Wins

It's okay to admit:

confusion

fear

failure

mistakes

uncertainty

These make the notebook believable.

Perfect people don't exist.

Neither should perfect notes.

---

# Leave Space

Not every note needs a conclusion.

Sometimes ending with a question is stronger.

Example:

Maybe the best opportunities are the ones we never planned.

I still don't know.

That feels real.

---

# Avoid Overwriting

One idea.

One note.

If a note contains three lessons,

split it.

Readers remember one clear thought better than five average ones.

---

# Emotional Balance

Notebook should never become too heavy.

Mix emotions.

Wonder.

Humour.

Failure.

Travel.

Gratitude.

Curiosity.

Hope.

Life isn't one emotion.

Notebook shouldn't be either.

---

# Titles

Titles should be simple.

Examples

The Old Nokia

Three Interviews

The Window Seat

Coffee After Meetings

Starting Again

Not Everything Needs A Plan

Avoid clickbait.

Avoid mystery.

Honesty is enough.

---

# Dates

Dates are optional.

Only include them when they add meaning.

Example

April 2026

The date itself becomes part of the memory.

---

# Quotes

Avoid famous quotes.

Notebook should preserve your own voice.

If someone remembers a sentence,

let it be yours.

---

# Humor

Gentle humor is welcome.

Real life is often funny.

Don't remove personality in pursuit of elegance.

A small smile is memorable.

---

# Length

If a note can say the same thing in fewer words,

choose fewer words.

Notebook should feel light,

never exhausting.

---

# Editing Checklist

Before publishing any note, ask:

Did this really happen?

Would I say this out loud?

Am I trying to sound smart?

Can this be simpler?

Is there only one main idea?

Would I still like this in five years?

If any answer feels wrong,

edit again.

---

# Publishing Rule

Not every thought deserves publishing.

A note should earn its place.

Quality over quantity.

Always.

---

# The Notebook Promise

Every new note should leave the reader with one feeling:

"I'm glad they wrote this down."

---

# Definition of Done

Notebook succeeds when every page feels like it could have been written on different days,

across different years,

yet still sounds unmistakably like the same person.
