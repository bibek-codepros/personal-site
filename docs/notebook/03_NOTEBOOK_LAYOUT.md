# NOTEBOOK LAYOUT

Status: Production Ready

Version: 1.0

---

# Purpose

This document defines the complete visual and interaction design of Notebook.

Notebook is not another page.

Notebook is another reading experience.

Unlike Becoming, which tells one continuous story,

Notebook lets readers wander.

Discover.

Pause.

Return.

---

# Philosophy

Notebook should feel like opening a personal notebook left on a wooden desk.

Not a blog.

Not a dashboard.

Not a knowledge base.

Not a social feed.

Every interaction should encourage curiosity.

Never urgency.

---

# First Impression

When Notebook opens,

the visitor should immediately understand:

"I don't need to read this in order."

Every note should feel approachable.

---

# Overall Structure

Notebook

↓

Hero

↓

Introduction

↓

Category Filter

↓

Featured Notes

↓

All Notes

↓

Closing Reflection

Simple.

Calm.

Predictable.

---

# Hero

Notebook has a different hero than Becoming.

Example

NOTEBOOK

Small thoughts.

Real moments.

Things I wanted to remember before I forgot them.

The hero should feel welcoming.

Never dramatic.

---

# Introduction

One short paragraph.

Example

Some ideas become stories.

Others stay exactly as they are.

This is where I keep them.

---

# Categories

Categories should feel editorial.

Not technical.

Examples

Life

Learning

Leadership

Travel

Work

Questions

Random

Home

Books

Coffee

Do not overload visitors.

Keep filtering simple.

---

# Category Interaction

Categories filter instantly.

No page reload.

Smooth transition.

No flashy animation.

Filtering should feel effortless.

---

# Featured Notes

Display three to six featured notes.

Purpose:

Introduce the tone of Notebook.

Not necessarily the newest entries.

The strongest entries deserve visibility.

---

# All Notes

Below Featured.

Organized chronologically.

Newest first.

Allow visitors to simply continue reading.

---

# Card Philosophy

Cards should not feel like UI.

Cards should feel like paper.

Soft.

Calm.

Comfortable.

Minimal borders.

No heavy shadows.

Rounded corners only if subtle.

---

# Card Structure

Category

↓

Title

↓

Preview

↓

Metadata

↓

Read Note

Simple.

Nothing unnecessary.

---

# Metadata

Minimal.

Only include:

Reading Time

Date

Location (optional)

Example

3 min

April 2026

Bali

---

# Hover

Very subtle.

Slight elevation.

Tiny movement.

Nothing dramatic.

Readers should feel invited.

Not interrupted.

---

# Opening A Note

When opening a note,

transition should feel like opening a page.

Not loading a new application.

Scrolling position should feel natural.

---

# Reading Width

Maximum

680px

Never wider.

Notebook should remain comfortable to read.

---

# Typography

Large title.

Comfortable paragraph spacing.

Short line length.

Notebook is built for reading.

Everything else supports that.

---

# Images

Images remain optional.

If used,

they should support the note.

Never decorate it.

A note without an image should feel complete.

---

# Pull Quotes

Notebook entries may contain one highlighted sentence.

Presentation

Centered.

Large.

Generous whitespace.

This creates rhythm.

---

# Related Notes

At the end of each note,

show three related entries.

Related by:

Theme

Category

Emotion

Not date.

Readers should naturally continue.

---

# Empty State

If a category has no notes,

show a thoughtful message.

Example

Nothing here yet.

Life will eventually give me something worth writing.

Avoid generic empty states.

---

# Search (Future)

Search should feel like searching memories.

Placeholder

Search thoughts, places, lessons...

Not

Search posts...

Language matters.

---

# Reading Progress

Notebook should not show progress bars.

This isn't a course.

Readers should never feel pressured to finish.

---

# Mobile Experience

Notebook should feel equally calm on mobile.

Cards stack naturally.

Reading remains comfortable.

No dense layouts.

No tiny controls.

---

# Accessibility

Keyboard navigation.

Readable contrast.

Logical headings.

Large tap targets.

Reduced motion support.

Notebook should be welcoming to everyone.

---

# Motion

Motion should be almost invisible.

Fade.

Tiny movement.

Gentle transitions.

Never distract from the words.

---

# Future Features

Notebook may eventually include

Favorites

Collections

Random Note

Share Thought

Reading History

Bookmarks

These should feel like quiet enhancements,

not product features.

---

# Closing Reflection

Notebook ends with a gentle reminder.

Example

Some thoughts stay with us.

Others quietly make room for new ones.

Thanks for reading mine.

---

# Definition of Done

Notebook succeeds when visitors stop browsing...

...and start wandering.

They should never feel like they're consuming content.

They should feel like they're discovering someone's thoughts,

one page at a time.
