# Project HOME Design System

Version: 1.0

Status:
Production

---

# Philosophy

Design is invisible.

Visitors should remember stories.

Not colors.

Not animations.

Not UI components.

Design exists to create comfort.

Never attention.

---

Every screen should feel:

Calm

Warm

Editorial

Intentional

Minimal

Timeless

Human

Premium

Quiet

Never:

Corporate

Flashy

Over-designed

Trendy

Busy

Cold

Apple

Notion

Kinfolk

Linear

# Color Philosophy

The interface should feel like paper.

Not glass.

Not plastic.

Not neon.

Warm backgrounds.

Dark readable text.

Very restrained accent color.

Minimal.

---

# Cards

Never glassmorphism.

Never excessive blur.

---

# Buttons

---

# Icons

Lucide Icons only.

Simple.

Consistent.

No colorful illustrations.

---

# Images

Photography first.

Avoid stock photos.

Real moments.

Real people.

Real environments.

---

# Illustration Style

Only if required.

Minimal line art.

Monochrome.

Editorial.

---

# Motion Philosophy

Motion is breathing.

Not performance.

Animations should be barely noticeable.

Visitors should feel them.

Not watch them.

---

# Motion Timing

Fast

200ms

Normal

350ms

Slow

500ms

Avoid anything longer than 700ms.

---

# Allowed Motion

Fade

Opacity

Translate Y

Small Scale

Stagger

Crossfade

---

# Forbidden Motion

Bounce

Spin

Elastic

Shake

Flash

Crazy Parallax

Typewriter Effects

Cursor Trails

Fireworks

---

# Scroll Behaviour

Scrolling should feel effortless.

Never force scroll effects.

Content is more important than animation.

---

# Dividers

Thin.

Quiet.

Optional.

Never decorative.

---

# Empty Space

Whitespace is a design element.

Never try to fill every gap.

Silence improves storytelling.

---

# Responsive Philosophy

Desktop is spacious.

Tablet is comfortable.

Mobile is intimate.

Never hide content without reason.

---

# Accessibility

Minimum contrast AA.

Keyboard accessible.

Visible focus.

Reduced motion support.

Readable font sizes.

Accessible forms.

---

# Performance

Design decisions should improve performance.

Prefer CSS over JavaScript.

Prefer static assets over heavy libraries.

Lazy load images.

Optimize fonts.

---

# Consistency

One button style.

One heading style.

One spacing system.

One animation language.

Consistency builds trust.

---

# North Star

When making design decisions ask:

Does this design help the visitor feel at home?

If yes,

keep it.

If not,

simplify it.
