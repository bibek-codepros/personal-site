# EDITORIAL SYSTEM

Status: Production Ready

Version: 1.0

---

# Purpose

This document defines the editorial system of HOME.

It is not a UI specification.

It is not a design system.

It is the invisible framework that makes every page feel like it belongs to the same beautifully crafted publication.

The goal is simple:

A visitor should immediately recognize HOME without needing to see the logo.

The editorial language itself becomes the identity.

---

# Philosophy

HOME should feel closer to:

• a hardcover memoir

• a premium travel journal

• an independent magazine

• a thoughtfully designed coffee-table book

than a personal website.

The interface exists only to support reading.

Nothing competes with the story.

---

# Editorial Principles

Every page should follow these principles.

## 1. Calm

Never overwhelm.

Every page should feel quiet.

Whitespace is allowed to exist.

Silence is part of the design.

---

## 2. Rhythm

Large.

Small.

Pause.

Continue.

Repeat.

The eye should never become tired.

The layout should naturally guide reading.

---

## 3. Intentionality

Nothing is decorative.

Every line.

Every icon.

Every divider.

Every image.

Every animation.

Must have a purpose.

---

## 4. Consistency

Readers should never need to learn a new layout.

Every chapter follows familiar rules.

Comfort creates immersion.

---

## Editorial Grid

Use a simple editorial grid.

Maximum reading width:

680px

Maximum content width:

1200px

Large margins.

Large breathing room.

The page should never feel crowded.

---

# Vertical Rhythm

Use generous spacing.

Suggested rhythm:

Section → 120px

Chapter → 160px

Paragraph group → 48px

Quote → 96px

Reflection → 120px

Image → 72px

Never compress spacing simply to fit more content.

Whitespace is storytelling.

---

# Editorial Hierarchy

Every page follows the same hierarchy.

Eyebrow

↓

Title

↓

Subtitle

↓

Meta

↓

Divider

↓

Body

↓

Reflection

↓

Transition

Readers subconsciously learn this rhythm.

---

# Page Openings

Every major page begins similarly.

HOME

↓

Section Name

↓

Title

↓

Short Introduction

↓

Content

This creates familiarity.

---

# Page Endings

Every page ends intentionally.

Never simply stop.

The ending should gently point toward the next experience.

Examples:

Continue Reading

↓

Open Notebook

↓

Start a Conversation

↓

Return Home

The visitor should always feel guided.

Never abandoned.

---

# Editorial Dividers

Avoid decorative flourishes.

Use simple dividers.

Examples:

────────────

•

Small uppercase labels

Very subtle lines

Nothing ornate.

---

# Captions

Captions are important.

Every image may include:

Location

Year

Memory

Context

Example:

Bali, Indonesia

April 2026

My first time seeing the ocean.

Captions should feel handwritten rather than technical.

---

# Pull Quotes

Each long story should contain one memorable sentence.

Pull quotes create breathing space.

Rules:

Centered.

Large typography.

Generous whitespace.

No boxes.

No quotation graphics.

Only words.

---

# Margin Notes

Future versions of HOME may include margin notes.

Examples:

A thought.

A date.

A lesson.

A definition.

A location.

These should remain optional.

Never mandatory.

---

# Editorial Components

Every page should reuse the same editorial language.

Examples:

Section Divider

Chapter Header

Pull Quote

Reflection

Memory Card

Timeline

Image Caption

Notebook Snippet

Conversation Prompt

Readers should feel continuity.

---

# Tone of Voice

HOME never shouts.

Avoid:

Huge marketing headlines.

Overly emotional copy.

Artificial inspiration.

Corporate language.

Instead use:

Simple.

Honest.

Reflective.

Confident.

Human.

---

# Photography Philosophy

Photos should document.

Not advertise.

The viewer should feel:

"I've been invited into someone's memories."

Not:

"I'm looking at a portfolio."

---

# Illustration Philosophy

Illustrations explain memories.

They never decorate empty space.

Every illustration should answer:

"What memory does this represent?"

If none,

remove it.

---

# Motion Philosophy

Motion is invisible.

The best animation is one nobody notices.

Every movement supports:

Reading.

Reflection.

Orientation.

Nothing more.

---

# Editorial Consistency Checklist

Every new page should answer:

□ Does it feel like HOME?

□ Does it respect whitespace?

□ Does it encourage reading?

□ Does it use the same editorial rhythm?

□ Does it feel handcrafted?

If any answer is "No",

continue refining.

---

# Definition of Done

The editorial system succeeds when visitors stop noticing interface decisions entirely.

Instead, they remember:

the stories,

the emotions,

and how HOME made them feel.
