# Before You Write A Single Line Of Code

Stop.

Do not start coding.

Do not redesign anything.

Do not improve anything.

Read first.

Understand first.

Feel first.

Only then build.

---

# What HOME Is

HOME is not a portfolio.

HOME is not a personal brand.

HOME is not a resume.

HOME is not a startup landing page.

HOME is not a productivity blog.

HOME is not a collection of projects.

HOME is not trying to impress anyone.

HOME is a digital memoir.

It documents one ordinary person's journey through curiosity, failure, opportunity, growth and becoming.

Its purpose is not to convince people that Bibek is successful.

Its purpose is to remind people that they can become someone too.

If you ever lose this idea,

everything else becomes meaningless.

Before finishing,

close the editor.
