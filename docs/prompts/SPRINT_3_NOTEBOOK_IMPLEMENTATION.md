# Editorial Direction

Notebook is NOT a blog.

Notebook is NOT chronological documentation.

Notebook should feel like opening someone's personal notebook.

Every note is a quiet memory.

Every note should feel intentional.

Reading Notebook should feel slower than reading Becoming.

---

# User Experience Goals

Visitors should forget they are reading markdown files.

Instead they should feel like they're reading pages from a beautifully designed journal.

Navigation should encourage reading sequentially.

Previous

↓

Current

↓

Next

No infinite scrolling.

No overwhelming archive.
