# HOMEPAGE UI REVIEW

Status: Creative Director Review

This document is NOT an implementation guide.

It is a design critique.

The homepage should be reviewed against every point below before considering it complete.

Do not stop after fixing obvious issues.

Keep refining until the homepage feels intentional.

---

# SECTION 01

## First Impression

★★★★★

Within 5 seconds the visitor should understand:

This is not a portfolio.

This is not a blog.

This is someone's story.

If the homepage still resembles a personal portfolio,

continue refining.

---

# SECTION 02

## Hero

★★★★★

The hero must create curiosity.

Visitors should immediately want to scroll.

Avoid introducing Bibek through credentials.

Introduce him through emotion.

The headline should feel unforgettable.

Whitespace around the hero should increase focus.

CTA should naturally invite exploration.

---

# SECTION 03

## Reading Rhythm

★★★★★

Never create long uninterrupted reading sections.

Alternate:

Story

↓

Whitespace

↓

Quote

↓

Illustration

↓

Story

↓

Cards

↓

Whitespace

The page should breathe.

---

# SECTION 04

## Typography

★★★★★

Review every heading.

Review every paragraph.

Check:

• hierarchy

• spacing

• line-height

• paragraph width

• visual rhythm

Typography should feel premium.

---

# SECTION 05

## Storytelling

★★★★★

Every section must answer:

"Why should I keep reading?"

If curiosity drops,

rewrite the section.

---

# SECTION 06

## Buttons

★★★★☆

Buttons should feel human.

Avoid:

Learn More

Read More

Explore

Prefer:

Walk with me →

Turn the page →

Continue →

Keep Reading →

Buttons should sound like HOME.

---

# SECTION 07

## Chapter Cards

★★★★★

Each chapter should feel like opening a book.

Every card should include:

Chapter Number

Icon

Title

Short emotional summary

Read →

Hover state should be elegant.

---

# SECTION 08

## Icons

★★★★★

Use Lucide Icons.

Never emojis.

Never decorative icons.

Every icon must reinforce the story.

Icons should be consistent in:

stroke

size

alignment

spacing

---

# SECTION 09

## Illustrations

★★★★☆

Illustrations should feel like memories.

Not decoration.

Each illustration should connect directly with the story beside it.

If an illustration could belong on any website,

replace it.

---

# SECTION 10

## Layout

★★★★★

Every section should have a different visual rhythm.

Avoid repetitive layouts.

Alternate:

text left

text right

centered quote

chapter grid

single column

This keeps scrolling engaging.

---

# SECTION 11

## Motion

★★★★★

Review every animation.

Ask:

Does this support reading?

If not,

remove it.

Animation should never become the main attraction.

---

# SECTION 12

## Color

★★★★☆

Color should support hierarchy.

Never dominate it.

Typography remains the strongest visual element.

---

# SECTION 13

## Quotes

★★★★★

Quotes deserve breathing room.

Large typography.

Centered.

Minimal distractions.

Visitors should pause naturally.

---

# SECTION 14

## Whitespace

★★★★★

Whitespace is part of the design.

If any section feels crowded,

increase spacing.

Never reduce spacing simply to fit more content.

---

# SECTION 15

## Current Journey

★★★★☆

Avoid looking like LinkedIn skills.

Instead,

communicate values.

Learning.

Curiosity.

Research.

Family.

Leadership.

Life.

---

# SECTION 16

## Footer

★★★★★

The visitor should feel like they are leaving someone's home.

Not leaving a website.

The final sentence should stay with them.

Links should become secondary.

Emotion should come first.

---

# SECTION 17

## Mobile Review

★★★★★

Review every section on mobile.

Questions:

Is reading comfortable?

Do headings wrap naturally?

Are cards easy to tap?

Does spacing still breathe?

Nothing should feel compressed.

---

# SECTION 18

## Performance

★★★★★

Review:

Images

Animations

Fonts

Bundle size

Accessibility

Maintain premium performance.

---

# SECTION 19

## Emotional Audit

★★★★★

Read the homepage from top to bottom.

Forget code.

Forget UI.

Ask:

Would I continue reading?

Would I share this with a friend?

Would I remember this tomorrow?

If not,

continue refining.

---

# SECTION 20

## Final Creative Director Checklist

The homepage is approved only when:

□ It no longer feels like a portfolio.

□ It feels like entering someone's world.

□ Every section has a purpose.

□ Every sentence earns its place.

□ Every illustration supports a memory.

□ Every icon supports meaning.

□ Typography feels editorial.

□ Motion feels invisible.

□ Whitespace feels intentional.

□ Visitors naturally want to open "Becoming."

---

# Definition of Done

The homepage should make someone think:

"I came here expecting a portfolio.

Instead...

I found a story."
