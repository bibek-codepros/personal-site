# HOMEPAGE ART DIRECTION

Status: Production Ready

This document defines the visual identity of HOME.

It is NOT a UI specification.

It is a creative direction document.

The objective is to ensure every visual decision supports the feeling of HOME.

---

# Design Philosophy

HOME should never feel like:

• a startup landing page
• a SaaS website
• a portfolio
• a blog
• a resume

HOME should feel like:

A beautifully designed memoir.

Think of someone inviting you into their world.

Everything should encourage slowing down.

Reading.

Thinking.

Feeling.

---

# Color Philosophy

The homepage should not rely on color.

Whitespace creates hierarchy.

Typography creates emotion.

Illustrations create personality.

Accent color should only appear:

Buttons

Links

Tiny highlights

Hover states

Never dominate the page.

---

# Typography

Typography is the primary design element.

Large hero.

Editorial headings.

Readable paragraphs.

Generous spacing.

Comfortable width.

Reading should feel effortless.

Hierarchy should be obvious without using excessive font weights.

---

# Reading Width

Maximum paragraph width:

Approximately 650–720px

Never allow long text to stretch across the screen.

Reading should resemble a printed book.

---

# Spacing Philosophy

Whitespace is content.

Every major section should breathe.

Suggested rhythm:

Large section

↓

Very generous whitespace

↓

Quote

↓

Whitespace

↓

Story

↓

Whitespace

↓

Illustration

↓

Whitespace

Never stack dense sections together.

# Photography Placeholders

Photography should feel documentary.

Not posed.

Not stock.

Until real photography exists,

use elegant placeholders.

Examples:

[ Childhood Photo ]

[ First HTML ]

[ Boarding Pass ]

[ Bali Sunrise ]

[ Coffee Shop ]

[ Notebook ]

[ Mum ]

[ Office ]

Each placeholder should already reserve space.

Never use Lorem Ipsum images.

---

# Motion Principles

Motion should be nearly invisible.

If visitors notice animations,

they are too strong.

Allowed:

Fade

Blur

Opacity

Small translateY

Slow parallax

Soft image reveal

Avoid:

Bounce

Rotation

Zoom

Elastic

Slide from extreme edges

Animations should support reading.

Never interrupt reading.

---

# Hero Animation

Headline

Fade + translateY

0.5s

Supporting copy

0.7s

Button

0.9s

Background

Very subtle movement.

Almost static.

---

# Scroll Behaviour

Reading should feel cinematic.

Not endless.

Sections should appear naturally.

Allow generous spacing between transitions.

Never create visual fatigue.

---

# Quotes

Quotes deserve their own breathing room.

Large italic typography.

Centered.

No illustration.

No distraction.

Just words.

---

# Buttons

Buttons should feel understated.

Rounded.

Minimal.

Comfortable padding.

Good hover state.

Never oversized.

Avoid gradients.

Avoid glowing effects.

---

# Chapter Cards

Chapter cards should feel like opening a book.

Suggested hierarchy:

Chapter Number

↓

Icon

↓

Title

↓

Short description

↓

Read →

Large hover area.

Very subtle hover animation.

Slight lift.

No dramatic scaling.

---

# Footer

The footer should feel like someone walking you to the front door.

Quiet.

Warm.

Personal.

It should not feel like website navigation.

Links should become secondary.

The final sentence should stay with the reader.

---

# Accessibility

Motion reduction support

Keyboard navigation

Proper heading structure

Readable contrast

Large touch targets

Readable line height

Accessible focus states

---

# Overall Experience

If someone only remembers one thing after leaving HOME...

It should not be the design.

It should be the feeling.

Visitors should think:

"I don't know this person.

But somehow...

I feel like I do."

That is the visual success metric.
