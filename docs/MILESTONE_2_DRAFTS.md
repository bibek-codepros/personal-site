# A Note On Method Before The Drafts

Every change below is **subtraction, or reordering of your own existing sentences** — never a new sentence, never an invented detail, never a paraphrase dressed up as your voice.

This is worth stating plainly because it changed how a couple of these drafts turned out. My first attempt at the Army Interviews rewrite, for example, started drifting toward inventing a small sensory detail (something about tea outside a door) to give the "three days of silence" more texture. That would have been manufacturing a memory that isn't yours, which is exactly what `EDITORIAL_AUDIT.md` says never to do. I threw it out and redid it using only sentences you already wrote. Every draft below follows that same rule — if a piece needed more presence somewhere, the fix was cutting what surrounded it, not adding to it.

One consequence of that discipline: a couple of these drafts are smaller, more conservative trims than the Repetition Map's recommendation technically allowed for. I'd rather show you a safe, honest, smaller cut than a bigger one I had to invent material to achieve.
