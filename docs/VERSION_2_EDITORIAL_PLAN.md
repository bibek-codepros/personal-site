## A Roadmap, Not A Rewrite

> Reference `docs/EDITORIAL_AUDIT.md` and `docs/EDITORIAL_LANGUAGE.md` before acting on anything in this document.

# Purpose

This document does not change a single sentence of HOME.

It maps what should change, why, in what order, and at what risk — so Version 2 can be approved as a whole before it becomes twenty-six separate conversations.

Everything below comes from an actual, complete read of the site: the Homepage, all six Becoming chapters, and all twenty Notebook Volume 1 entries.

---

# What We Found

Two patterns explain almost every revision proposed below.

**Pattern 1 — The Ending Habit.** Of the six Becoming chapters, five close with a stated reflection and a life-lesson. Of the twenty Notebook entries, roughly sixteen do the same. This is not a flaw in any single piece. It is a habit that became visible only by reading all twenty-six at once.

**Pattern 2 — The Same Scene, Retold.** Several life events are told at three or even four levels of the site, often in nearly identical language:

- The Army interviews: Homepage (compressed) → Becoming ch.1 → Notebook #4. Told fully three times.
- Choosing technology / Code Pros: Becoming ch.2 → Notebook #5.
- Copying HTML / the boilerplate: Becoming ch.2 → Notebook #6 → Notebook #7. Nearly beat-for-beat in two places.
- "The Place That Believed In Me": Homepage → Becoming ch.3 → Notebook #8. Three pieces, same title, same thesis.
- Bali / Window Seat: Becoming ch.5 (404 lines, contains every sub-scene) → Notebook #12, #13, #14, #15 each re-tell one fragment of that same chapter, often in near-identical phrasing (the slippers negotiation, the mum quote, the currency exchange, the Starbucks/milk-tea detail all appear twice, worded almost the same way).
- Success and family: Becoming ch.6 → Notebook #16.

Neither pattern is a writing-quality problem. The prose is good. The problem is that the site currently has no rule for which layer owns which level of detail, so each layer defaults to retelling the whole thing.

---

# How Revisions Are Classified

Every item below is tagged with one of three types, so effort and risk stay honest:

- **Structural** — a decision about which piece owns which scene or detail. No sentence-level rewriting; sometimes trimming, sometimes nothing at all.
- **Emotional** — a change to *how a piece ends*, using `EDITORIAL_LANGUAGE.md`. The scene stays; the last beat changes.
- **Polish** — removing a sentence that explains something the scene already showed. Subtraction, not rewriting.

# Milestones

The order below differs slightly from a straightforward Homepage-first sequence, for one reason: the Homepage's Window Seat section and Current Journey section both depend on decisions made deeper in the site. Fixing them first would mean fixing them twice.

**Milestone 1 — Repetition Map & Ownership Decisions**
Not a rewrite. A short decision memo covering the six overlap clusters identified above — which layer (Homepage / Becoming / Notebook) keeps which level of detail. Every later milestone depends on this one. Effort: Medium. Risk: Low — it is a planning step, not a content change.

**Milestone 2 — Window Seat (Becoming ch.5 and Notebook #12–15)**
The largest and highest-priority body of work in Version 2. Becoming ch.5 gets an ending-technique change; the four Notebook satellites get trimmed to their one non-redundant beat each, per Milestone 1's decision. Effort: High. Risk: Medium.

**Milestone 3 — Homepage Editorial Pass**
Window Seat section and Quote Moment section, now that Milestone 2 has settled what they should point to. One Minute Story and Code Pros touched only if needed. Effort: Medium. Risk: Low–Medium.

**Milestone 4 — Current Journey**
The values-grid reframe. Independent of the milestones above — could run in parallel with Milestone 2 if preferred. Effort: Medium. Risk: Low.

**Milestone 5 — Becoming Endings**
Chapters 1, 2, and 4 — swap the reflection-plus-forward-teaser closes for other techniques from `EDITORIAL_LANGUAGE.md`. Chapters 3 and 6 stay untouched. Effort: Medium. Risk: Medium.

**Milestone 6 — Notebook Endings & Remaining Clusters**
Childhood/Nokia, Learning to Code, Leadership, and Today/Closing clusters. The Army/Career-Pivot and Bali clusters are largely resolved by Milestones 1–2 and only need final ending-technique passes here. Effort: Medium. Risk: Low–Medium.

**Milestone 7 — Final Editorial Consistency Review**
A complete reread of the whole site against both `EDITORIAL_AUDIT.md` and `EDITORIAL_LANGUAGE.md`. Specifically checks: did ending-technique variety start turning into its own new formula; is voice still consistent; did the repetition decisions from Milestone 1 actually land the way they were meant to. Effort: Low. Risk: Low — this milestone only catches problems, it doesn't create new ones.

# A Note Before Approving

The two highest-risk items in this entire plan are the same two pieces every review pass so far has flagged as HOME's strongest material: Becoming ch.3 ("The Place That Believed In Me") and its homepage counterpart. They appear in this document mainly to say: leave them almost exactly as they are. The safest recommendation for Version 2's best writing is restraint, not revision.
