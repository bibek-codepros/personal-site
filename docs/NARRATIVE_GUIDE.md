# NARRATIVE_GUIDE.md

# Narrative Guide

Version: 1.0

Project:
HOME

---

# Introduction

Narrative is the product.

The code exists to deliver it.

The design exists to support it.

The animations exist to guide it.

Everything serves the story.

Never reverse this relationship.

---

# The Golden Rule

Every page should answer one question.

"Who is Bibek?"

Not

"What has Bibek achieved?"

Achievements support the narrative.

They never replace it.

---

# The Reader

Imagine one person.

Not a thousand.

One.

Someone who has never met Bibek.

Someone curious enough to stay.

Write only for that person.

---

# Writing Style

HOME should read like a conversation.

Not an autobiography.

Not a marketing page.

Not a LinkedIn profile.

Not a company website.

Every sentence should feel natural.

If something sounds like corporate writing,

rewrite it.

---

# Tone

The tone should be:

Calm.

Honest.

Reflective.

Confident.

Human.

Never arrogant.

Never dramatic.

Never overly emotional.

The website should earn emotion.

Not demand it.

---

# Vocabulary

Prefer simple words.

Simple language is stronger.

Instead of:

"Commenced"

Use:

"Started"

Instead of:

"Leveraged"

Use:

"Used"

Instead of:

"Accomplished"

Use:

"Built"

Natural language creates trust.

---

# Paragraph Length

Paragraphs should breathe.

Prefer:

1–4 sentences.

Avoid large blocks of text.

Whitespace is part of the storytelling.

---

# Titles

Titles should create curiosity.

Not explain everything.

Examples:

Welcome.

Becoming.

The Place That Believed In Me.

Window Seat.

Today.

Small titles.

Big meaning.

---

# Story Structure

Every story should follow this rhythm.

Beginning

↓

Challenge

↓

Learning

↓

Reflection

Not

Beginning

↓

Achievement

↓

Achievement

↓

Achievement

Growth matters more than success.

---

# Reflections

Every major chapter should end with a reflection.

Not a conclusion.

Ask:

What changed?

What did I learn?

How did this shape me?

Reflection is where the emotional value lives.

---

# Career

Career is only one chapter.

Never let career dominate the website.

The website is about a person.

Not a position.

---

# Code Pros

This chapter deserves special care.

Never present Code Pros as a company profile.

Never advertise it.

Instead,

tell the truth.

Code Pros gave Bibek opportunities to grow.

That is enough.

Gratitude is stronger than promotion.

---

# Leadership

Leadership should appear naturally.

Avoid statements like:

"I became a leader."

Instead,

show responsibility increasing over time.

Readers should discover leadership.

Not be told about it.

---

# Singapore → Bali

This chapter is symbolic.

The journey represents perspective.

Not luxury.

Do not focus on:

Hotels.

Flights.

Tourism.

Instead focus on:

Growth.

Gratitude.

The feeling of realizing how far you've come.

---

# Success

HOME does not celebrate titles.

HOME celebrates progress.

Progress is quieter.

More meaningful.

More relatable.

---

# Failures

Do not hide struggles.

Struggles make achievements believable.

Failure should never become self-pity.

Instead,

show resilience.

---

# Humility

Humility is one of the strongest characteristics of HOME.

Never exaggerate.

Never overclaim.

Never write to impress.

Write to connect.

---

# Humor

Small moments of humor are welcome.

Forced humor is not.

If a sentence naturally smiles,

keep it.

---

# Emotion

Emotion should emerge naturally.

Never manipulate the reader.

Never write to make people cry.

Write honestly.

Real emotion follows.

---

# Timeline

The website follows time.

Not importance.

Childhood.

Learning.

Development.

Operations.

Leadership.

Today.

This order should remain stable.

---

# Future

HOME is unfinished.

That is intentional.

Visitors should feel that the story continues.

The final page should never feel like an ending.

Only the current chapter.

---

# Visual Storytelling

Large empty spaces are acceptable.

Silence is part of the experience.

Do not fear whitespace.

Whitespace gives readers time to think.

---

# Quotes

Quotes should be rare.

When used,

they should feel earned.

Never fill the website with inspirational quotes.

Original reflections are more powerful.

---

# The Visitor's Journey

The emotional journey should be:

Curiosity

↓

Comfort

↓

Trust

↓

Respect

↓

Inspiration

Never reverse this order.

Trust comes before admiration.

---

# Every Section Must Answer

Why is this here?

If the answer is:

"Because it looks cool."

Remove it.

If the answer is:

"Because it helps people understand Bibek."

Keep it.

---

# The Last Impression

When visitors leave HOME,

they should feel like they have visited someone.

Not consumed content.

That feeling is the success metric.

---

# The North Star

If future writing ever feels uncertain,

return to this sentence.

HOME is a place where people meet a human being before they meet a professional.

Protect that sentence.

Everything else is flexible.
