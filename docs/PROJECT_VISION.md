# Before You Write A Single Line Of Code

Stop.

Read this file completely.

Project HOME is not another Next.js website.

It is not a portfolio.

It is not a landing page.

It is not a personal brand website.

Project HOME is a digital home.

Everything you build must help visitors know Bibek as a human being before they know him as a professional.

Technology exists to support emotion.

Never the opposite.

---

# Mission

Your responsibility is to build a calm, narrative-first digital home.

Visitors should leave feeling:

"I know this person."

NOT

"I know his skills."

If a technical decision makes the website feel more impressive but less human...

Choose the human solution.

Always.

Notion

---

# Typography

Typography carries emotion.

Use whitespace generously.

Never compress content.

Never make text difficult to read.

Headings should breathe.

Paragraphs should feel conversational.

---

# Motion Philosophy

Animation should never ask for attention.

Animation should simply guide attention.

Allowed:

Fade

Opacity

Soft translateY

Subtle stagger

Gentle reveal

Forbidden:

Bounce

Elastic

Overspin

Flash

Excessive parallax

Confetti

Attention-seeking effects

Technology must disappear.

---

# Homepage Objective

The homepage has one responsibility.

Reduce emotional distance.

Nothing else.

Do not try to communicate every achievement.

Do not list every technology.

Do not overload visitors.

Curiosity is more powerful than information.
