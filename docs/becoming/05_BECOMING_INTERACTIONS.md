# BECOMING INTERACTIONS

Status: Production Ready

Version: 2.0

---

# Purpose

This document defines the emotional choreography of the Becoming experience.

It does NOT define animations.

It defines feelings.

Every interaction should disappear into the story.

The visitor should never notice animation.

They should only notice emotion.

---

# Principle

Interaction should never exist for delight.

Interaction exists to control rhythm.

Every fade.

Every pause.

Every reveal.

Every transition.

Exists for one reason:

To make reading feel human.

---

# The Golden Rule

Never animate because something appeared.

Animate because something matters.

---

# Reading Pace

Reading is not scrolling.

Reading is breathing.

The interface should respect this.

Avoid constant movement.

Instead create quiet moments.

Allow visitors to stop naturally.

Never rush.

# Chapter Introduction

Every chapter begins with restraint.

Sequence

Chapter Number

↓

↓

Subtitle

↓

Reading Time

↓

↓

Each element fades upward.

Never simultaneously.

This creates rhythm.

---

# Reading Motion

Scrolling should feel natural.

Do not animate every paragraph.

Instead:

Paragraphs already in viewport

Remain static.

Paragraphs entering viewport

Receive:

Opacity

0 → 100%

Translate Y

8px

Duration

400ms

No blur.

No scaling.

Visitors should barely notice.

---

# Quote Reveal

Quotes deserve their own moment.

When a quote enters the viewport:

Fade

600ms

No movement.

No scaling.

The words already carry enough weight.

Whitespace creates emphasis.

Animation should never compete.

---

# Image Reveal

Images should appear like memories.

Animation:

Opacity

Translate

Very slight

500ms

Delay

100ms

Never zoom.

Never bounce.

Never rotate.

Images should quietly appear.

---

# Memory Blocks

Memory Blocks receive a different treatment.

As they enter:

Border appears first.

Then title.

Then content.

Small stagger.

This creates a feeling of discovery.

---

# Timeline Blocks

Timeline items appear sequentially.

Not all together.

Visitors should naturally read downward.

Avoid dramatic effects.

---

# Reflection Section

Reflection is sacred.

When entering viewport:

Everything else stops.

Reflection fades slowly.

800ms

Large whitespace.

Allow silence.

No surrounding animations.

---

Sequence

The visitor should never feel pushed.

Instead:

Invited.

# Continue Button

Hover

Tiny upward movement

2px

Duration

150ms

Background transitions softly.

Arrow slides

4px

Nothing more.

Luxury lives in restraint.

---

# Chapter Transition

Click

↓

Fade

↓

Short pause

↓

Next chapter loads

↓

Chapter intro sequence begins

Never hard-cut.

Transitions should feel like turning a page.

---

# Scroll Position

Starting a new chapter:

Always scroll to top.

Smoothly.

Never preserve previous scroll.

Every chapter deserves a fresh beginning.

---

# Ambient Motion

Very subtle.

Optional.

Background gradient moves almost imperceptibly.

Only if performance remains excellent.

Visitors should never consciously notice.

---

# Cursor

Default cursor.

No custom cursor.

Reading does not need novelty.

---

# Buttons

Buttons should never pulse.

Never glow.

Never bounce.

Confidence needs no attention.

---

# Hover States

Hover should reassure.

Not entertain.

Buttons

Soft elevation.

Links

Gentle underline animation.

Chapter Cards

Very subtle lift.

Nothing else.

---

# Reduced Motion

Respect

prefers-reduced-motion

Disable:

Stagger

Fade

Translate

Only maintain essential transitions.

Accessibility comes before aesthetics.

---

# Loading States

Avoid skeleton loaders.

Prefer:

Simple fade.

Or nothing.

Fast websites don't need loading theatre.

---

# Performance Budget

Interactions should never reduce performance.

Target:

60 FPS

No layout shifts.

No unnecessary JavaScript.

Animation should remain GPU accelerated.

---

# Sound

None.

Silence belongs to reading.

---

# Mobile Behaviour

Exactly the same philosophy.

Less motion.

Never more.

Mobile users should experience the same emotional rhythm.

---

# Things We Will Never Do

❌ Confetti

❌ Typewriter effects

❌ Auto scrolling

❌ Background music

❌ Parallax everywhere

❌ Heavy blur animations

❌ Flashy transitions

❌ 3D effects

❌ Scroll hijacking

❌ Fancy page flips

HOME is confident enough to stay quiet.

---

# Success Metric

Visitors should never say:

"The animations were nice."

Instead they should say:

"I don't know why...

but reading this felt different."

That is the goal.

---

# Creative Director's Rule

The best interaction is the one nobody notices—

because it felt completely natural.
