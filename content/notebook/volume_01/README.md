# Notebook

HOME is more than a collection of pages.

It is a collection of memories.

The Notebook is where those memories live.

Unlike **Becoming**, which tells one continuous story, Notebook preserves the smaller moments that quietly shaped that story.

Some are only a few sentences.

Some become reflections.

Some are memories I never wanted to forget.

Some are questions I'm still trying to answer.

None of them were written to teach.

They were written to remember.

---

# Philosophy

Every notebook entry begins with a real experience.

Experience becomes observation.

Observation becomes reflection.

Nothing is invented.

Nothing is exaggerated.

Nothing exists to impress.

If a note doesn't feel honest, it doesn't belong here.

---

# Structure

```
content/notebook/

README.md

volume_01/
volume_02/
volume_03/
...
```

Each volume is a self-contained collection.

Every note lives inside its own Markdown file.

This keeps the notebook scalable as it grows over the years.

# Editorial Principles

Notebook follows one simple rule:

> Write to remember.
> Never write to impress.

Every note should sound like a conversation over coffee.

Not a blog.

Not LinkedIn.

Not a motivational speech.

Just an honest memory shared with another person.

---

# Long-term Vision

Notebook is never finished.

As life continues,

new notes will be added,

new volumes will appear,

and HOME will slowly become a living archive rather than a completed project.

That is exactly how it should be.
